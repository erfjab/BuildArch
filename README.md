# استودیو جباری — وب‌سایت

سایت معرفی استودیوی معماری و طراحی داخلی «استودیو جباری» در ارومیه. فقط فارسی، راست‌به‌چپ، کاملاً فرانت‌اند و بدون مرحله‌ی build.

## اجرا

فایل `index.html` را مستقیم در مرورگر باز کنید، یا برای تست دقیق‌تر یک سرور ساده بالا بیاورید:

```powershell
npx serve .
```

## ساختار فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | ساختار صفحه و ترتیب بارگذاری اسکریپت‌ها |
| `assets/css/style.css` | تمام استایل‌ها (یک تم روشن) |
| `assets/js/content.js` | **همه‌ی محتوا**: متن‌ها، آمار، خدمات، پروژه‌ها، تیم، تماس، لوگوی پیام‌رسان‌ها |
| `assets/js/engine.js` | موتور ایزومتریک روی canvas و ابزارها |
| `assets/js/scenes.js` | صحنه‌های ایزومتریک: شهر صفحه‌ی اصلی، پنج صحنه‌ی خدمات، انیمیشن کارت زیربنا |
| `assets/js/main.js` | قرار دادن محتوا در صفحه، راه‌اندازی صحنه‌ها، اسکرول و تعامل‌ها |
| `AGENTS.md` | راهنمای کار با پروژه برای دستیارهای هوش مصنوعی |

## تغییر محتوا

برای تغییر متن‌ها، شماره‌ها یا پروژه‌ها فقط `assets/js/content.js` را ویرایش کنید. به طراحی دست نزنید.

## اطلاعاتی که هنوز نمونه‌اند

این‌ها ساختگی‌اند و باید با اطلاعات واقعی جایگزین شوند (همه در `content.js`):

- شماره تلفن‌ها، آیدی پیام‌رسان‌ها، ایمیل و نشانی دفتر
- مختصات دفتر برای لینک‌های مسیریابی (`lat` و `lng`؛ الان مرکز ارومیه است)
- آمار کارنامه (سال‌ها، تعداد پروژه، ساختمان‌ها، شهرها، زیربنا)
- نام و مشخصات پروژه‌ها
- نام، سمت و سابقه‌ی اعضای تیم و نقل‌قول بنیان‌گذار
- لوگوهای پیام‌رسان‌ها نسخه‌ی ساده‌شده‌اند؛ بهتر است فایل‌های رسمی جایگزین شوند
